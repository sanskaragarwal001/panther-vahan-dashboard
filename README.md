# 🐆 Panther Vahan Dashboard

**Panther Vahan Dashboard** is a high-performance frontend application built with **SolidJS** and **TailwindCSS**. It serves as a visual interface for the [*Panther Vahan Analysis*](https://github.com/sanskaragarwal001) Playwright server, providing real-time statistics and insights into the sales of e-rickshaws and three-wheeler brands.



## 🚀 Features

*   **Brand Analytics:** Track and compare sales performance across multiple e-rickshaw and 3-wheeler manufacturers.
*   **Monthly Filtering:** Deep-dive into specific timeframes with monthly sales sorting and viewing options.
*   **Data Export:** Seamlessly download sales statistics into **Excel format** for offline reporting.
*   **Reactive UI:** Built with SolidJS for lightning-fast updates and a smooth user experience.
*   **Responsive Design:** Styled with TailwindCSS to ensure the dashboard looks great on any device.

---

## 🛠️ Tech Stack

*   **Framework:** [SolidJS](https://www.solidjs.com/) (Fine-grained reactivity)
*   **Styling:** [TailwindCSS](https://tailwindcss.com/) (Utility-first CSS)
*   **Data Source:** Panther Vahan Analysis (Playwright-based scraper/server)
*   **Package Manager:** pnpm

## 📦 Getting Started

### Prerequisites

This project uses **pnpm** for dependency management. If you don't have it installed:
```bash
npm install -g pnpm
```

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/panther-vahan-dashboard.git
    cd panther-vahan-dashboard
    ```

2.  **Install dependencies:**
    ```bash
    pnpm install
    ```

### Available Scripts

| Command | Action |
| :--- | :--- |
| `pnpm dev` | Runs the app in development mode at `http://localhost:3000` |
| `pnpm build` | Bundles the app into the `dist` folder for production |
| `pnpm start` | Locally previews the production build |

---

## 📊 Usage

### Viewing Statistics
Upon launching, the dashboard fetches the latest scraped data from the Vahan Analysis server. Use the **Brand Selector** or the **Monthly Toggle** to filter the visual data.

### Exporting Data
Click the **"Export to Excel"** button located at the top right of the data table to generate a `.xlsx` file containing your current filtered view.

## 🌐 Deployment

The `dist` folder generated by `pnpm build` contains static assets. You can deploy this to any static hosting provider:

*   **Vercel / Netlify:** Connect your GitHub repo for automatic deployments.
*   **Static Host:** Upload the contents of `/dist` to any server (NGINX, Apache, etc.).
